# Moosic_Playlist_Generation_Project

## 🎵 Moosic: Smart Playlist Generation Using Clustering and Spotify Audio Features

## 📑 Summary
This project explores using audio features from the Spotify API to automatically generate playlists grouped by musical similarity. By applying KMeans and KMeansConstrained clustering with feature weighting, we built balanced, perceptually relevant playlists without relying on genre, artist, or title metadata.

## 🛠️ Languages and Libraries Used
  - Python
  - Pandas
  - Scikit-learn
  - Matplotlib
  - Seaborn
  - Spotipy
  - Kmeans-constrained

## 📚 Key Learnings
- Learned to guide clustering with feature weighting based on human perception.
- Improved skills in preprocessing, Scalling, and constrained clustering.
- Gained experience in communicating insights for both technical and non-technical audiences.

## 🧗 Challenges Overcame
- Unbalanced clusters were fixed by using KMeansConstrained with size limits.
- Identified and adjusted feature importance to improve perceptual grouping.

## 💭 Additional Reflections
This project showed how simple models, when adapted thoughtfully, can deliver human-aligned results. Future steps include integrating genre or lyrics and exploring soft clustering approaches.
